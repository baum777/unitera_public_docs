# Assets

Reserved for public diagrams, exported architecture images, presentation graphics, and logos that are explicitly cleared for public use.

Prefer Mermaid-in-Markdown for architecture diagrams because it remains diffable, reviewable, and source-controlled. Static exports should reference the Markdown source that generated or explains them.

## Brand media in use

- `documentation-banner.png`: unmodified documentation banner from the UNITERA Brand System Bundle v1.0.0.
- `crane.png`: unmodified Level B origami crane from the same bundle.

These media provide the visual identity of the documentation. They do not demonstrate execution permission or product maturity. The bundle’s brand architecture has candidate status; this use does not change that status.

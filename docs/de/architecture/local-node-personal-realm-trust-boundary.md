# Lokale und persönliche Vertrauensgrenze

Status: `PUBLIC_ABSTRACTED`

Ein lokaler Node ist eine kontrollierte Grenze zwischen UNITERA und lokalen Daten oder Systemen. Lokale Erreichbarkeit bedeutet weder Authority noch Ausführungserlaubnis.

Der Personal Realm bewahrt persönliche Kontinuität. Institutionelles Wissen bleibt davon getrennt. Ein persönlicher Beitrag wechselt nur über eine ausdrückliche, begrenzte und nachvollziehbare Grenze in institutionelle Arbeit.

```text
Personal Memory != Institutional Knowledge
Local reachability != Authority
Device ownership != business permission
Resume context != Authority
```

Gerätewechsel oder eine neue Session dürfen Kontext fortsetzen, aber keine Rechte erweitern. Aktuelle Identität, Zweck, Organisationsbezug und Zulässigkeit werden erneut geprüft.

> Conceptual public projection — not deployment, service, repository, protocol or security topology.

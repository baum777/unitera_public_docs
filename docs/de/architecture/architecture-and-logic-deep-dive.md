# Architektur und Logik

Status: `PUBLIC_ABSTRACTED`
Authority: keine durch dieses Dokument

UNITERA trennt institutionelles Wissen, Kontext, Kognition, Authority, Ausführung und Evidenz. Diese Trennung macht leistungsfähige KI nutzbar, ohne Verantwortung an ein Modell abzugeben.

```text
REALITY → KNOW → THINK → PROPOSE → AUTHORIZE → ACT → PROVE → LEARN
```

## Kerninvarianten

```text
Evidence != Truth
Context != Permission
Cognition != Authority
Approval != Execution
Receipt != Verification
Model != Institution
```

Institutionelles Wissen wird aus nachvollziehbaren Quellen und Entscheidungen aufgebaut. KNOW stellt zweckgebundenen Kontext bereit. THINK analysiert und plant. Erst eine getrennte Governance- und Ausführungsgrenze kann reale Wirkung zulassen. PROVE hält Ergebnis und Unsicherheit prüfbar; LEARN führt nur geprüfte Veränderungen in institutionellen Zustand zurück.

> Conceptual public projection — not deployment, service, repository, protocol or security topology.

# Review und Assurance

Status: `PUBLIC_ABSTRACTED`

UNITERA trennt fachliche Prüfung, technische Verifikation und Authority. Reviewer können Evidenz bewerten und Risiken sichtbar machen, erzeugen dadurch aber keine Ausführungsberechtigung.

Öffentlich wird nur der grobe Reifegrad beschrieben. Konkrete Reviewer-Zuordnungen, interne Klassen, Teststände und Bindungen bleiben in den zuständigen internen Quellen.

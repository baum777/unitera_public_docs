# Glossary

| Term | Public definition |
|---|---|
| **Company Brain** | Governed organizational knowledge/foundation context; authority is owned outside the consumer runtime. |
| **KNOW** | Context Runtime: compiles sufficient, tenant-bound, provenance-aware context. |
| **THINK** | Cognition Runtime: analysis, planning, replanning, findings, and action proposals within bounded compute/autonomy. |
| **ACT** | Execution Control: evaluates and dispatches governed effects through explicit authority and evidence boundaries. |
| **Action Proposal** | Cognition output proposing an effect; not permission to execute. |
| **Capability Request** | Request to use a capability; not a grant. |
| **Capability Grant** | Explicit bounded authorization to proceed under defined conditions. |
| **Receipt** | Evidence that an execution attempt/provider interaction occurred; not proof of business outcome. |
| **Verification** | Independent determination of the relevant outcome/state after execution. |
| **Tenant** | Institutional security and authority boundary. |
| **Registry** | Cross-repo reference/provenance/adoption surface; references authority and does not create it. |
| **Public Projection** | Human-readable documentation derived from verified sources with no authority of its own. |
| **Source Pointer** | Explicit mechanism for selecting a current source bundle/state; pointer review is separate from source materialization. |
| **Local Runtime Node** | Candidate governed local deployment/trust boundary; locality alone does not create trust. |
| **Personal Realm** | Owner-approved first-class person-bound continuity and isolation domain for a persistent UNITERA relationship; not a Company Tenant, Membership, PlatformPrincipal, or authority domain. |
| **Personal Domain** | Transition/alternative term superseded by the preferred term **Personal Realm**. |
| **Personal Tenant** | Historical working term for Personal Realm; discouraged in normative use because Tenant already means an institutional security and authority boundary. |
| **Companion** | Persistent personal interaction and cognition projection of the Personal Realm; not Company Brain, Membership authority, or Capability Grant. |
| **Personal Memory** | Deliberately retained user-bound continuity information; not conversation history, Runtime State, or institutional truth. |
| **PersonalIdea** | Personal possibility/direction that may develop or enter Circling; not a Claim or Decision. |
| **PersonalConcept** | Developed personal model/design/solution candidate; distinct from canonical terminology Concept Identity and from an institutional Claim. |
| **PersonalPlan** | Personal planning structure; not a Work Order or Company Objective. |
| **Circling** | Owner-approved first-class semantic lifecycle/relationship for attention without commitment; not a universal container object, Priority, Work Order, Claim, or Decision. |
| **Contribution Proposal** | Personal-side proposal the Companion may prepare; crossing into an institutional lifecycle requires explicit user confirmation. |
| **PersonalContextProjection** | Explicit user-authorized, tenant-/purpose-/scope-/time-bound projection of selected personal context; not raw Personal Memory or Company ownership. |
| **CrossBoundaryResidencyDecision** | Decision governing whether company-derived context may persist in Personal Memory and under which restrictions. |
| **Relationship Familiarity** | How well the Companion knows a person; may improve interpretation, but does not create permission. |
| **Qualification** | Evidence of reliable Companion behavior in a defined capability/scope; may support promotion eligibility, but is not authority. |
| **Global Companion Autonomy Tier** | Maximum qualitative personal-autonomy ceiling; does not directly authorize a capability. |
| **Effective Capability Tier** | Runtime-attenuated autonomy currently exercisable for one capability/scope; never above its capability delegation or global ceiling. |
| **Companion Shadow Guard** | Independent anomaly/reasonableness guard for autonomous effectful Companion actions; may freeze, deny, escalate, or allow an existing authority path, but never creates authority. |

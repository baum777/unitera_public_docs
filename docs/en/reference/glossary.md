# Glossary

| Term | Public definition |
|---|---|
| **Human Agency** | Ability of people and institutions to set goals, boundaries, and binding decisions. |
| **Model Sovereignty** | Freedom to select and change models without transferring or expanding authority. |
| **Company Brain** | Governed organizational knowledge and institutional context. |
| **KNOW** | Compilation of sufficient, purpose-bound context. |
| **THINK** | Analysis, planning, and proposals within bounded cognition. |
| **ACT** | Governed translation of an authorized action into effect. |
| **Action Proposal** | Proposal for an effect; not permission to execute. |
| **Capability Grant** | Explicit bounded permission under defined conditions. |
| **Receipt** | Evidence of an execution attempt; not proof of business outcome. |
| **Verification** | Independent determination of the relevant result after an effect. |
| **Tenant** | Institutional security and authority boundary. |
| **Personal Realm** | Person-bound continuity and isolation domain. |
| **Companion** | Persistent personal interaction and cognition projection. |
| **Personal Memory** | Deliberately retained user-bound continuity information. |
| **Circling** | Attention to a topic without silent commitment. |
| **Resume Continuity** | Traceable continuation of work without silent transfer of rights. |
| **Public Projection** | Curated, lossy explanation with no authority of its own. |

# Glossary

| Term | Public definition |
|---|---|
| **Company Brain** | Governed organizational knowledge/foundation context; authority is owned outside the consumer runtime. |
| **KNOW** | Context Runtime: compiles sufficient, tenant-bound, provenance-aware context. |
| **THINK** | Cognition Runtime: analysis, planning, replanning, findings, and action proposals within bounded compute/autonomy. |
| **ACT** | Execution Control: evaluates and dispatches governed effects through explicit authority and evidence boundaries. |
| **Action Proposal** | Cognition output proposing an effect; not permission to execute. |
| **Capability Request** | Request to use a capability; not a grant. |
| **Capability Grant** | Explicit bounded authorization to proceed under defined conditions. |
| **Receipt** | Evidence that an execution attempt/provider interaction occurred; not proof of business outcome. |
| **Verification** | Independent determination of the relevant outcome/state after execution. |
| **Tenant** | Institutional security and authority boundary. |
| **Registry** | Cross-repo reference/provenance/adoption surface; references authority and does not create it. |
| **Public Projection** | Human-readable documentation derived from verified sources with no authority of its own. |
| **Source Pointer** | Explicit mechanism for selecting a current source bundle/state; pointer review is separate from source materialization. |
| **Local Runtime Node** | Candidate governed local deployment/trust boundary; locality alone does not create trust. |
| **Personal Domain** | Candidate user-bound continuity and isolation domain for a person's persistent UNITERA relationship; not a Company Tenant or authority domain. |
| **Personal Tenant** | Working term for Personal Domain; not canonical terminology in this public projection. |
| **Member Companion** | Candidate persistent personal interaction and cognition projection; not Company Brain, Tenant Assignment, or authority. |
| **Personal Memory** | Candidate deliberately retained user-bound continuity information; not Runtime State or institutional truth. |
| **Circling** | Candidate incubation state for potentially meaningful material that is not yet a priority, Work Order, Claim, or Decision. |
| **Contribution Proposal** | Candidate explicit proposal to move personal material toward an institutional lifecycle; not Claim inclusion or Brain activation. |

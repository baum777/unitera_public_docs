# Cognition

Status: `PUBLIC_ABSTRACTED`

Cognition interprets purpose-bound context, analyzes options and creates or revises proposals. It owns neither institutional truth nor authority.

```text
Model capability != Authority
Provider change != permission change
Better model != more authority
```

Model selection and permitted use are governed outside model output. A model cannot choose its own authority ceiling or an authority-bearing execution route.

## Remote-capable and cost-aware

The newer owner-confirmed direction treats remote cognition as the normal operating path while local inference remains optional. This applies only to context that is eligible for remote processing by purpose, realm and data-release rules; remote use is not data-egress permission. Canonical adoption of this extended direction is still pending.

Token and context economy is treated as a quality and cost principle: UNITERA should transmit only sufficiently relevant context, reuse safe stable context components, avoid regenerating freshness-safe results unnecessarily, and use more intensive cognition only when justified.

Caches do not store authority. Before a real effect, permission, freshness and other materially relevant prerequisites are checked again.

```text
Least sufficient context > maximal context
Cache reuse != authority reuse
Cheaper route != lower quality requirement
Stronger route != more authority
```

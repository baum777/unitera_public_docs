# Discovery and Company Brain

Status: `PUBLIC_CORE`

The Company Brain is an organization's versioned institutional context. It is neither model memory, an agent nor execution permission.

Discovery gathers and structures traceable foundations. People review uncertainty, conflicts and open decisions. Only explicit activation makes a reviewed state active institutional context.

In `/work`, this context appears as an understandable foundation for active work, sources, next steps and Needs You — not as a technical object tree.

Needs You surfaces decisions requiring human input. Quick Actions offer bounded next steps; Chat supports explanation, exploration and drafting in the context of active work. None of these interface elements creates authority or execution permission.

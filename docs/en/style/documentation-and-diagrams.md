# Documentation & Diagram Conventions

Public pages use only `PUBLIC_CORE`, `PUBLIC_ABSTRACTED`, and `PUBLIC_STATUS`.
Internal source detail is not reproduced. The composition rule in the
[public disclosure policy](../reference/public-disclosure-policy.md) applies
across pages as well as within a single page.

Diagrams explain concepts and relationships. They carry this notice:

> Conceptual public projection — not deployment, service, repository, protocol or security topology.

Use GitHub-native Mermaid and the rules in [`MERMAID.md`](../../../MERMAID.md).
Meaning must be conveyed through labels and shapes, not color alone. Receipt
and Verification remain separate concepts.

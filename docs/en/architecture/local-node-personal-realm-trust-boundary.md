# Local and personal trust boundary

Status: `PUBLIC_ABSTRACTED`

A local node is a controlled boundary between UNITERA and local data or systems. Local reachability means neither authority nor execution permission.

The Personal Realm preserves personal continuity. Institutional knowledge remains separate. A personal contribution crosses into institutional work only through an explicit, bounded and traceable boundary.

```text
Personal Memory != Institutional Knowledge
Local reachability != Authority
Device ownership != business permission
Resume context != Authority
```

A device or session change may continue context but cannot expand rights. Current identity, purpose, organizational context and admissibility are checked again.

> Conceptual public projection — not deployment, service, repository, protocol or security topology.

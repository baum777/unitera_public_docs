# Architecture and logic

Status: `PUBLIC_ABSTRACTED`
Authority: none through this document

UNITERA separates institutional knowledge, context, cognition, authority, execution and evidence. This separation makes capable AI useful without transferring accountability to a model.

```text
REALITY → KNOW → THINK → PROPOSE → AUTHORIZE → ACT → PROVE → LEARN
```

## Core invariants

```text
Evidence != Truth
Context != Permission
Cognition != Authority
Approval != Execution
Receipt != Verification
Model != Institution
```

Institutional knowledge grows from traceable sources and decisions. KNOW supplies purpose-bound context. THINK analyzes and plans. Only a separate governance and execution boundary may permit real-world effects. PROVE keeps outcomes and uncertainty reviewable; LEARN returns only reviewed change to institutional state.

> Conceptual public projection — not deployment, service, repository, protocol or security topology.
